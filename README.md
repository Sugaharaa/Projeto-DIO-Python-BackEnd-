# 🏦 Sistema Bancário em Python

Projeto desenvolvido como parte do desafio da Formação Python Developer da DIO.

## 📋 Funcionalidades

* Depósito
* Saque
* Extrato
* Controle de saldo
* Limite de 3 saques
* Limite de R$ 500,00 por saque

## 🛠️ Tecnologias

* Python 3
* Git
* GitHub

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/Sugaharaa/Projeto-DIO-Python-BackEnd-.git
```

Entre na pasta:

```bash
cd Projeto-DIO-Python-BackEnd-
```

Execute o programa:

```bash
python SistemaBancario.py
```
